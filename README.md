Это учебный проект (лабораторная работа), представляющий собой скрипт на языке Python, который определяет операционную систему и собирает набор ключевых параметров о системе, оборудовании и окружении.

Скрипт корректно работает в ОС Windows, macOS и Linux, cобирает информацию о системе, "железе", сети и окружении пользователя.
Результат работы сохраняется в файл `system_info.json` в структурированном и читаемом виде.
Используется обработка исключений для предотвращения падений скрипта при невозможности получить какой-либо параметр.


Скрипт собирает следующие данные:

-Информация о системе:
Название ОС (e.g., 'Darwin', 'Windows'), версия релиза системы, детальная информация о версии.

-Информация об оборудовании:
Архитектура процессора (e.g., 'x86_64', 'arm64'), имя/модель процессора, количество ядер ЦП.

-Сетевая информация:
Сетевое имя компьютера, локальный IP-адрес.

-Окружение:
Имя текущего пользователя, путь к домашней директории, версия интерпретатора Python, запустившего скрипт, путь к исполняемому файлу Python.
